# Idiomind

**Idiomind** is a cross-platform language-learning application built with **Qt and C++**.

The project aims to **port the Idiomind experience to other operating systems**, making the same language-learning concept available across desktop and mobile platforms.

## Platforms

Idiomind Qt is being developed for:

* **Linux**
* **Windows**
* **Android**

The Qt framework provides a common foundation for the application across these platforms, while allowing platform-specific adaptations where necessary.

## Project

The purpose of this project is to bring Idiomind to systems beyond its original environment while maintaining the same core concept and user experience.

The application is being developed with a shared **C++/Qt codebase**, with the goal of keeping the different platform versions as consistent as possible.

```text
                 Idiomind
                    │
             C++ / Qt core
                    │
        ┌───────────┼───────────┐
        │           │           │
      Linux       Windows     Android
```

## Status

**Active development**

The project is currently being developed and ported across the supported platforms.
