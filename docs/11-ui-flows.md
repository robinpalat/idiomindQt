# 10 - UI flows (original YAD-based behavior)

All UI is YAD (GTK3 dialogs generated by bash). Window props are consistent:
`--name=Idiomind --class=Idiomind --window-icon=$DS/images/logo.png
--gtkrc=$DS/default/gtkrc.cfg`. Theme file `gtkrc.cfg` is applied to every
dialog. Keep the same interaction contract in QML: confirm/dialog buttons,
`|`-separated output, `FALSE/TRUE` checklists.

## Main windows

### Notebook (topic) — `items_list.sh`
- `notebook_1` **Info**: `tpc_view` — topic title, image, note (`note.inf`),
  dates, `nwrd/nsnt/nimg/naud/nsze`, category, author, links; edit note button.
- `notebook_2` **Index/Review**: the practice/learning list (checklist fed from
  `index` file), status label (`_stats`), action buttons:
  - **Practice** → practice/strt.sh
  - **Review** → apply `mark_as_learned` when stts∈{1,5,6}, refresh
  - **To learn** → `mark_to_learn`
  - **Listen / Play all** → play.sh bucle
  - **Word viewer / Sentence viewer** (`vwr`, `word_view`, `sentence_view`)
    opened by double-click on an item: shows big trgt, translation, note,
    `sentence_parts` with `grmr` colors, example, image, audio; edit via
    `dlg_form_2`.
- `notebook_3` **Manage**: resources (`attatchments`), export (audio/csv/idmnd/
  pdf/tsv), backup/restore, stats, about, check updates, share (`upld.sh`).

### Add note — `add.sh` / `mods/add/add.sh`
- `new_items` flow: YAD form `dlg_form_1` (trgt field + CB topic selector +
  buttons **Clipboard watcher / OCR / Screen clipping / Add audio file /
  sentence editor / Add**). If a translation field present → `dlg_form_2`.
- Entering text triggers background `process()`:
  1. call OCR/import if those buttons used;
  2. `translate` trgt→srce (if enabled), 2s wait;
  3. `tts_word` / `fetch_audio` for words found in wrds;
  4. `img_word` (image download) with validity check (`file -b --mime-type | grep image`);
  5. build flat `data` line via `eval line="$(sed -n 2p $DS/default/vars)"`;
  6. append to `$DC_tlt/data`, then `check_index`.
- Sentence add: `dlg_checklist_3`: first column checks the sentences (the ones
  over length get red hint color), second pane CB target topic, buttons
  **Edit/Add**. Selecting opens sentence word picker.
- Word add from selection: `dlg_checklist_2`: checkbox list + form (note &
  example pre-filled) + Apply/Cancel.
- `msg_3` dialogs with **Play** button link to `play.sh play_word "$trgt"`.

### Global
- Topic selector `chng.sh`: YAD file/notebook; used with first-run hint string.
- Preferences `cnfg.sh`: notebook (global + addons). Fields: language selectors,
  play options (loop, pause_rep, pause_osd, audio), automated download toggles
  (gramr, trans, dlaud, ttrgt), interface (gtkrc), behavior (swind, stsks),
  tray, intro (itray), stats, addons config (`Resources/cnfg.sh`).
- Tray `itray`: appindicator menu → Add/Play/Stop (`stop.sh 2`)/Index/Topics/
  quit (`stop.sh 1`); monitors `$DT/playlck` via GFileMonitor; topic entries
  from `$DC_s/tpc` lines; tasks submenu from `$DT/tasks`.
- Clip watcher `clipw`/`clipw.sh`: watches clipboard 5 min; adds selected note
  to `$DT/tpe` topic; notifies via notify-send; 2nd invocation kills it.

## Message helpers (`ifs/cmns.sh`)
- `msg` — single OK button
- `msg_2` — 2 buttons (custom labels)
- `msg_4` — extended (OK/Stop/Wait) + progress lock
- `progress` — progress pipe (`--auto-close`)
- `internet` — connectivity check (curl to google) — some paths exit if offline
- `yad_kill` — close all matching yad windows (used to close forms before
  starting new ones)
- `cleanups file*` — rm files/dirs (used everywhere for temp cleanup)

## Hotkeys / misc behaviors to replicate
- double-click item → word/sentence viewer;
- `--always-print-result` on forms (print all fields), `--print-all`;
- checkboxes initialized `TRUE/FALSE` from stored `mark` config;
- `FALSE`/`TRUE` values are significant literal strings (parsed by colorize and
  by checklist builders).
