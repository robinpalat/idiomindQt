## Modules added (idiomind_storage)

### 1. `TopicDataRepository` (src/storage/topic, new)
Topic-scoped persistence of items, index, stts/stts.bk/note, plus DB list tables.
Stateful: caches the parsed segment lines of .conf/data at load (mirrors Bash reading the data file
into an in-memory list; honestly just Ordering + the sed edits need the raw lines).

API (all take `tlng`, `topic` as strings; `AppPaths` injected):
- Items:
  - `QList<FlatItemCodec::DecodedItem> loadItems(tlng, topic)` — read data lines (strip trailing \n/\r),
    keep every non-empty line; decode into {Item, segments} WITHOUT writing anything (no write-on-read).
  - `bool appendItem(tlng, topic, const Item &item)` — replica of `mods/add/add.sh index()` NON-edit
    branch: if `item.trgt` empty -> false; if `.conf` missing -> false; if `grep -Fo "trgt{<trgt>"` matches
    any existing line (prefix `trgt{` then the trgt text followed by `}`? Bash: `grep -Fo "trgt{${trgt}}"`,
    i.e. literal substring `trgt{<trgt>` — a line `trgt{abc...}` does NOT match `trgt{ab}` because of the
    closing `}` — so we match literal substring `trgt{<trgt>}` actually Bash does NOT include the closing
    brace, but the substring `trgt{ab` also appears inside `trgt{abernathy}`! So Bash duplicate-guard is a
    PREFIX/substring match. REPRODUCE: skip when any data line contains the literal text `trgt{<trgt>`.
    Document. ) -> return false (silent skip).
  - type 1: unset wrds/grmr/link/defn (Qt: clear those fields on the stored copy), insert into
    learning + words tables; type 2: clear defn, insert learning + sentences. `index` append
    `<trgt>\nFALSE\n<srce>\n`. `data` append template-encoded line + '\n' (14-field canonical encode).
  - `bool updateItem(tlng, topic, const QString &targetTrgt, const Item &changes, UpdateResult *res)`
    — replica of `mngr.sh edit_item` + `index edit`:
    1. locate line by `trgt{<targetTrgt>}` (Bash uses edit_pos by `trgt{<newTrgt>}`; we locate the
       CURRENT trgt; keep behavior: search literal `trgt{<target>`). Not found -> false.
    2. if trgt renamed to newTrgt: `index edit` behavior = `update <ta> set list='<new>' where list='<old>'`
       for learning learnt words sentences marks; AND practice files `sed -i "s|^<old>$|<new>|"` per file.
    3. in-place data-line edit = sed field-replacement semantics: for each of the *changeable* fields
       (type, srce, exmp, defn, note, wrds, grmr, mark, cdid [+ trgt/grmr when renamed]), REPLACE the
       value of that named segment with the new value; leave ALL other segments byte-identical
       (preserves slXX/imgr/unknown). Segments absent from the line are NOT added (sed wouldn't).
       For type rename Bash ALSO does `grmr{oldgrmr} -> grmr{newtrgt}` when trgt changed — replicate
       only the observable effects we document; the risky grmr/trgt global-sed is part of the original,
       implement the final same-topic sed block (`type srce exmp defn note wrds grmr mark cdid`) plus
       the trgt rename handled by index edit; srce placeholder/re-translation belongs to translator (F7)
       — do NOT simulate network: for F3.1 updateItem updates srce when provided, else keeps it).
    4. type changed (1<->2): move between words/sentences tables (`delete where list=<name>` + insert).
    5. audio/image renames are FS/UI (media) — OUT of F3.1 (documented; skip unless item fields only).
    6. after edit, refresh segments cache for that line and rebuild index if `colorizeRun` semantics
       (index always rebuilt by Bash when something changed: implement rebuildIndex after scale).
  - `bool removeItem(tlng, topic, const QString &trgt)` — replica of delete_item_ok (no dialogs):
    1. find line (literal `trgt{<trgt>`), derive cdid via `(?<=cdid{).*(?=})` of that line;
    2. remove data line (delete matching line);
    3. practice logs: remove whole-line matches, then drop empty lines, rewrite file;
    4. `delete from learning|learnt|words|sentences|marks where list='<trgt>'`;
    5. media files removed (mp3 by cdid, jpg by lowercased trgt) — filesystem side effects; implement
       (they are part of original delete), guarded by QFile::remove ignoring missing;
    6. if data line count < 200 and `.conf/lk` exists -> remove `lk`; if `.conf/feeds` exists ->
       append `<trgt>\n` to `.conf/exclude` (delete_item path);
    7. rebuildIndex. Reviews/id-counts untouched (quirk: nwrd/nsnt NOT decremented — document).
  - `bool writeDataFile(tlng, topic)` — used by tests for round-trip: serializes the cached DecodedItems
    (via reencodeItem) as `<line>\n` each; REPORT if this is NOT byte-identical for unmodified items
    (it should be). Also used by repair after restore.

- Index:
  - `QStringList loadIndex(tlng, topic)` — 3-line groups as-is (text/chk/srce); empty if file missing.
  - `bool validateIndex(tlng, topic, IndexReport *rep)` — pure read: (non-empty lines)/3 vs learning
    count (index0 == cnt1); returns mismatch (NO writes).
  - `bool rebuildIndex(tlng, topic, bool chkFlag)` — replica of `colorize` (tls.sh:1005-1058):
    acheck=config.acheck; learning, marks lists; grabar index = for each data line (stripped) whose trgt
    ∈ learning list, emit: text (bold `<b><big>` if ∈ marks else plain) / chk line (only log1 items:
    `TRUE` if log1 contains line AND acheck==TRUE AND chkFlag else `FALSE`; non-log1 items `FALSE`)
    / srce (segment index 1). log2 -> `<span color='#C15F27'>`, log3 -> `<span color='#AE3259'>`.
    chk line for logged items is FALSE except log1 form. Bytes: each group ends with '\n'. Touches
    DM_tlt mtime (Bash `touch`) -> apply. File replaced (write fresh).
  - `IndexReport {int indexCount; int learningCount; bool valid;}`.

- Topic files (stts / stts.bk / note):
  - `QString readStts(tlng, topic)` (first line, trimmed; "" if missing),
  - `bool  writeStts(tlng, topic, const QString &value)` (value + '\n'),
  - `bool  writeSttsBackup(tlng, topic)` (mv stts->stts.bk; then echo 0 > stts — update_lists path),
  - `bool  restoreSttsFromBackup(tlng, topic)` (whole-file restore + remove stts.bk),
  - `bool  removeSttsBackup(tlng, topic)`,
  - `QString readNote(tlng, topic)` (whole file),
  - `bool  writeNote(tlng, topic, const QString &text)`.

### 2. `ReviewRepository` (src/storage/topic, new)
- `Review load(tlng, topic)` — `select * from reviews` first row -> columns date1..date10 via
  `Review::setSqliteDate`; empty Review when no row.
- `bool store(tlng, topic, const Review &rp)` — ensure row exists (insert `(date1) values ('')` if none);
  `update reviews set dateN='<v>'` for each column whose value differs (write all 10 is fine; keep single-row).
- `bool clear(tlng, topic)` — delete all from reviews; insert `(date1) values ('')`.
- `bool backfillDate1IfEmpty(tlng, topic)` — if date1 empty -> `update ... set date1='%m/%d/%Y'` today.
- `int  countFilled(tlng, topic)` — Review::countFilled after load (mirrors `grep -c '[^[:space:]]'`).

### 4. `FlatItemCodec` extension (global namespace; no breaking API change)
- `struct DecodedItem { Item item; QList<QPair<QString,QString>> segments; };`
- `DecodedItem decodeWithSegments(const QString &line);` — split the line by `}` (like Bash
  `grep -oP '(?<=name{).*(?=})'` / `split('}','}\n')`): segment = `name{value` pairs; value up to next `}`.
- `QString reencodeItem(const DecodedItem &orig, const Item &cur);` — emit segments in ORIGINAL order;
  for canonical parseable segments take CURRENT value from `cur` (field-name-based replace, exactly the
  sed-op of edit_item); unknown segments (slXX/imgr if not modeled) keep ORIGINAL value. New canonical
  fields not present in orig.serge une append at canonical order end (append path uses `encode()`).
- `encode(item)` unchanged (14-field canonical writer for NEW items).

## Solidified decisions for F3.1
- loadTopic does NOT repair; repair = TopicRepairService::checkIndex called explicitly.
- .conf/stts is runtime authority (F2.2 kept); id.stts untouched.
- Reviews: single-row invariant; store/load full 10-date vector; backfill date1 rule; date9/10 LOST by
  db_reviews repair (reproduce: preserve date1..date8).
- Data table (tpc DB) is import-only / dormant: no writes from add/edit/delete (matches Bash) — DO NOT touch.
- id counts nwrd/nsnt not adjusted on delete (quirk, document).
- mkmn/.share/index, id .idmnd writer, .idmnd import: OUT of F3.1 (documented).
- Tests never point at real profile: AppPaths(homeDir=<QTemporaryDir>), AppPaths(tmpRoot=<QTemporaryDir>).
